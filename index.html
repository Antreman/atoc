ATM PIN Attempt System
Finite State Machine with limited tries: Try0 → Try1 → Try2 → Locked.
FSM state: TRY0  (q0)
Attempts used: 0 / 3  | Remaining: 3
Enter 4-digit PIN using keypad.
States: {TRY0 (q0), TRY1 (q1), TRY2 (q2), LOCKED (q3)}
Inputs: {correctPIN, wrongPIN}
Transitions:
TRY0 --wrongPIN--> TRY1
TRY1 --wrongPIN--> TRY2
TRY2 --wrongPIN--> LOCKED
Any state + correctPIN → “Access Granted” (no further transitions).
